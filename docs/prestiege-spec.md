# Prestiege - Luxury Marketplace Specification

## Project Name
Prestiege - Comprehensive multi-category luxury marketplace (web + mobile Expo compatible)

## Design Philosophy
- Following mvita-hq project patterns for mock data structure
- Portfolio-centric (collections/holdings) like ECR
- Cross-category discovery (JamesEdition)
- Data-rich (provenance, registry model)
- Expo + web compatibility (monorepo structure similar to mvita-hq)

## Core Categories
1. Real Estate (estates) - properties, compounds, estates, penthouses
2. Mobility - vehicles, aircraft, supercars, classics
3. Yachts - superyachts, megayachts, sailing
4. Jets - private jets, helicopters
5. Watches - haute horlogerie, limited editions
6. Jewelry - high jewelry, diamonds, gemstones
7. Bags - Hermès, Chanel, exotic skins (Birkin/Kelly etc)
8. Shoes - luxury footwear, limited editions
9. Fashion - ready-to-wear, couture
10. Art - fine art, sculptures, installations
11. Books - rare books, manuscripts, first editions
12. Spirits - rare whisky, champagne, cognac
13. Collectibles - memorabilia, objets d'art
14. Experiences - curated luxury experiences

## Data Model Principles
- Consistent ID structure
- Rich metadata (provenance, condition, location, insurance, valuation history)
- Multiple images, listing URLs
- Currency handling (USD base)
- Registry fields (chassis/VIN, serial, edition numbers)
- Following mvita-hq mockData patterns
